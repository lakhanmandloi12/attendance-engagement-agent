# Attendance & Engagement Agent

A Flask web app that analyzes a classroom photo with Google Gemini and
reports attendance count, engagement level, and teaching suggestions.

## Setup
1. pip install -r requirements.txt
2. Create a `.env` file with: GEMINI_API_KEY=your_key
3. python app.py
4. Open http://127.0.0.1:5000

## Tech
Python, Flask, Google Gemini (google-genai), HTML/CSS/JavaScript
